### Discovery — décisions de cadrage (séance 2026-06-18)

- **D-UX1 — Working mode : Fast path.** Lionel — *« fast »*. Conséquence : je drafte les 2 spines complètement avec des `[ASSUMPTION]` aux endroits où j'aurai inféré ; pas d'outils créatifs en cours de route ; itération sur les drafts.
- **D-UX2 — Référence aesthétique : NYT Cooking (primary) + Bear (secondary).**
  - **NYT Cooking** *(primary)* : langage visuel des Recettes *(carte photo-forward, serif éditorial fort, palette crème/ocre/bordeaux, layout magazine)*. Cardinal pour porter la métaphore *« livre de cuisine vivant »*.
  - **Bear** *(secondary)* : épure fonctionnelle des écrans non-Recette *(interactions tactiles mobile, swipes, densité maîtrisée, sobriété sans-serif corps)*. Cardinal pour porter la friction-zéro de la planification/listes.
  - **Refero non-utilisable directement** : URL par UUID, pas de slug. Drafte à partir de connaissance des 2 apps.
- **D-UX3 — Palette : chaude.** Crème, terracotta, sauge *(approximation NYT Cooking adaptée)*. Confirmé Lionel.
- **D-UX4 — Typographie : serif éditorial pour les titres + sans-serif pour le corps.** Confirmé Lionel.
  - **Choix tech [ASSUMPTION] :** **New York** *(iOS system serif)* pour les titres + **SF Pro Text** *(iOS system sans)* pour le corps. Justification : aligné NFR-X5 *(soutenabilité 1 dev — pas de web font à charger, zéro overhead perf, ships avec iOS)*. À reconsidérer si Lionel préfère un Google Font *(alternatives gratuites : Source Serif 4 + Inter)*.
- **D-UX5 — Mode sombre [ASSUMPTION] : pré-tokens prévus, activation reportée post-MVP.** Justification : NFR-X5 *(soutenabilité 1 dev)* — le mode sombre double le coût de tests pour un foyer iPhone qui peut basculer le système. Les tokens sont définis pour ne pas avoir à réécrire le DESIGN.md en v2.

### Décisions finalize (séance 2026-06-18)

Lève l'`[ASSUMPTION]` AS-UX1 du draft initial.
- **D-UX7 — Convention de référence DESIGN.md ↔ EXPERIENCE.md : nom seul (sans `{path.to.token}`).** Tranché en séance finalize *(reviewer rubric)*. Les tokens de DESIGN.md sont référencés par leur nom seul *(`accent-primary`, `surface-base`, etc.)*, sans préfixe `{colors.accent-primary}`. Justification : noms uniques dans le frontmatter, ambiguïté nulle ; allègement de lecture ; cohérent NFR-X5 *(soutenabilité)*. Documenté en intro EXPERIENCE.md.
